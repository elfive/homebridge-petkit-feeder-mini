This plugin logs into the Petkit server with your account, fetches the session and discovers the devices automatically. Test the login first, then choose the devices to control and save the config.
此插件通过 Petkit 账号登录服务器，自动获取会话并发现设备。请先测试登录，登录成功后选择要控制的设备并保存配置。
Note / 提示：Petkit only allows one active session per account, a dedicated account with shared devices is recommended, otherwise the App and this plugin will kick each other out.
Petkit 每个账号只允许一个活跃会话，建议使用专用账号并在主账号中共享设备，否则手机 App 与本插件会互相踢下线。
① Account Login / 账号登录
Choose the country / region of your account from the dropdown, this plugin connects to the official Petkit server of this country code automatically.
从下拉框中选择你账号所属的国家/地区，本插件会自动使用该国家代码对应的官方服务器地址。
Your Petkit account (email / phone number).
你的 Petkit 账号(邮箱/手机号)。
Only used to login the server.
仅用于登录服务器。
Logging into the Petkit server... / 正在登录 Petkit 服务器...
② Device Selection / 选择要控制的设备

Check the devices this plugin should control, and give each one a friendly name to identify it in HomeKit. Unchecked devices are not added to HomeKit.
勾选要由本插件控制的设备，并可以为每个设备设置一个便于识别的名称(将显示在 HomeKit 中)，未勾选的设备不会被添加到 HomeKit。
